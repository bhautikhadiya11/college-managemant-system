# 🎓 CampusFlow - Student & Professor Portal

Welcome to the frontend portal of **CampusFlow**, an advanced College Management System designed to streamline the academic experience for both Students and Professors.

## 🚀 Features

### For Students
- **Real-time Dashboard:** View attendance, pending assignments, and upcoming fees.
- **Attendance Tracking:** Keep track of subject-wise attendance and overall percentages.
- **Assignments:** Download materials, submit assignments, and view grades.
- **Fees Management:** Secure online fee payment integration (Razorpay).
- **Syllabus & Gallery:** Access course syllabus and college event galleries.

### For Professors
- **Smart Attendance:** Mark daily attendance with easy-to-use toggles and bulk actions.
- **Advanced Reporting:** Generate detailed attendance reports (Excel/Print) filtered by Date and Division.
- **Assignment Management:** Upload assignments and evaluate student submissions.
- **Syllabus Tracking:** Upload and manage subject syllabus materials.

## 💻 Tech Stack
- **Framework:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **HTTP Client:** Axios
- **Icons:** Lucide React

## 🛠️ Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/bhautikhadiya11/college-managemant-system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd college-managemant-system
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
